# String Algorithms

A collection of fundamental **String algorithms implemented in C** for Data Structures & Algorithms laboratory practice.

---

## 📌 Contents

This folder contains implementations of:

- Character Frequency — `character_frequency.c`
- Substring Extraction — `extract_substring.c`
- Palindrome Checking — `palindrome_string.c`
- Pattern Matching — `pattern_matching.c`

---

## 🎯 Key Learning Points

### 1. Character Frequency

**File:** `character_frequency.c`

- Counts the frequency of each character in a string.
- Uses character arrays and loops.
- Demonstrates string traversal.
- Helps understand character counting and frequency analysis.
- Time Complexity: **O(n)**.
- Space Complexity: **O(1)** for a fixed character set.

---

### 2. Substring Extraction

**File:** `extract_substring.c`

- Extracts a specific portion of a string.
- Uses string indexing and character arrays.
- Demonstrates how strings are stored and accessed in C.
- Helps understand substring positions and lengths.
- Useful for basic string manipulation.

---

### 3. Palindrome Checking

**File:** `palindrome_string.c`

- Checks whether a string reads the same forward and backward.
- Uses character comparison from both ends.
- Demonstrates string traversal and indexing.
