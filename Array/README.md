## 🎯 Key Learning Points

### Array Reverse

- Reverses the elements of an array.
- Uses **array indexing and swapping**.
- Swaps the first element with the last, second with second-last, and so on.
- Performs the operation **in-place** without using an extra array.
- Demonstrates array traversal, loops, and swapping.

### Example

```text
Original Array:
10 20 30 40 50

Reversed Array:
50 40 30 20 10
